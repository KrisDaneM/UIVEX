# UIVEX SEO Keyword Strategy

This research set contains **500 unique keyword and search-phrase ideas** grounded in components and workflows that UIVEX actually provides. It is a content-planning resource—not a meta-keywords list. Use phrases naturally where they answer user intent; do not paste them into hidden blocks or create thin doorway pages. No search-volume or difficulty figures are claimed.

## Usage principles

- Give each public page one primary topic and a small number of closely related secondary phrases.
- Keep titles, descriptions, headings, and body copy useful to people first.
- Consolidate overlapping intent into strong category, component detail, Playground, and Guide content.
- Map `/components/:slug` suggestions only to a matching registered component; never generate a page for a nonexistent pattern.
- Reassess wording as the registry grows and as real search-performance data becomes available.
